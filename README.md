# 📸 AI Lens Web

**A complete, sleek, fully functional web application** that brings the powerful visual search and AR identification experience of Google Lens directly to your browser.

## ✨ Features
- 📷 **Live Camera** – Real-time AI scanning with getUserMedia (mobile-friendly)  
- 🖼️ **Photo Upload** – Drag, drop or select any image  
- 🔍 **Multiple Modes** – Auto, Text, Translate, Plants & Animals, Shopping, Places, QR  
- 🪄 **AR Overlays** – Animated bounding boxes and live labels  
- 📊 **Instant Results** – Beautiful cards with match %, info and actions  
- 📖 **Scan History** – Saved with localStorage (persists between sessions)  
- 📱 **100% Mobile-First** – Perfect on phones, tablets & desktop  
- 🌐 **SEO Optimized** – Full meta tags, keywords, fast loading  

## 🛠️ Technologies Used
- 🔨 **HTML5** – Semantic markup + native camera API  
- 🎨 **CSS3** – Modern gradients, AR animations & dark theme  
- 📱 **Bootstrap 5** – Fully responsive & beautiful UI  
- ⚡ **JavaScript + jQuery** – Real-time detection & interactive logic  

## 🚀 How to Run
1. Download the 4 files into the **same folder**  
2. Open `index.html` in any modern browser  
3. Allow camera access and start identifying anything instantly!
